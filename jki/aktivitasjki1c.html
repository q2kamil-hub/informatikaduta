📦 Jelajah Jaringan: Petualangan Paket Data

"Ikuti perjalanan data dari pengirim ke penerima!"

📖 Materi Singkat Bagian 3

1. Apa Itu Protokol TCP/IP?

TCP/IP (Transmission Control Protocol / Internet Protocol) adalah aturan komunikasi yang digunakan perangkat di internet. Tanpa protokol ini, perangkat tidak bisa saling memahami saat bertukar data.

  • IP (Internet Protocol) — mengatur alamat dan rute pengiriman data.
  • TCP (Transmission Control Protocol) — memastikan data dikirim lengkap dan urut sampai tujuan.

2. Alamat IP — Identitas Perangkat

Setiap perangkat yang terhubung ke jaringan punya alamat IP unik, seperti alamat rumah. Contoh:

  • 192.168.1.10 — alamat IP lokal (di jaringan rumah/sekolah).
  • 8.8.8.8 — alamat IP server Google DNS di internet.

3. Paket Data — Data yang Dipecah

Saat kamu mengirim email atau membuka situs web, data tidak dikirim utuh. Data dipecah menjadi paket-paket kecil, lalu setiap paket dikirim melalui jaringan.

  • Setiap paket punya alamat pengirim dan alamat tujuan.
  • Paket bisa melewati jalur berbeda.
  • Di tujuan, paket disusun ulang menjadi data utuh.
📦 Analogi: Paket data seperti kiriman paket pos:
  • 📮 Alamat IP = alamat rumah
  • 📦 Paket data = kotak kiriman
  • 📡 Router = kantor pos yang mengarahkan
