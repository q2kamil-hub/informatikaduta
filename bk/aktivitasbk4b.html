1. Apa Itu Diagram Venn?

Diagram Venn adalah cara visual untuk menunjukkan hubungan antar himpunan. Setiap himpunan digambarkan sebagai lingkaran di dalam kotak (himpunan semesta).

2. Bagian-Bagian Diagram Venn

  • Kotak persegi panjang = himpunan semesta (S)
  • Lingkaran A = himpunan A
  • Lingkaran B = himpunan B
  • Area tumpang tindih (overlap) = irisan A ∩ B

3. Contoh Sederhana

Misal: A = {1, 2, 3, 4}, B = {3, 4, 5, 6}

• A saja = {1, 2}
• B saja = {5, 6}
• A ∩ B = {3, 4}
• A ∪ B = {1, 2, 3, 4, 5, 6}

4. Manfaat Diagram Venn

  • Visualisasi: Mempermudah melihat hubungan antar himpunan
  • Analisis: Membantu menemukan anggota irisan, gabungan, selisih
  • Pemecahan masalah: Sering dipakai di soal cerita himpunan
