🌐 Aktivitas: Stack di Sekitar Kita
📖 Cerita: Budi sedang mengerjakan tugas di laptopnya. Ia mengetik beberapa huruf, lalu salah dan menekan Undo. Setelah selesai, ia membuka browser untuk mencari referensi: Google, lalu Wikipedia, lalu YouTube. Saat ingin kembali ke Wikipedia, ia menekan Back. Di dapur, ibunya menumpuk piring yang baru dicuci.

Tanpa sadar, Budi dan ibunya sedang menggunakan struktur data yang sama — stack (tumpukan)! Tugasmu sekarang: jelajahi tiga tempat berbeda untuk menemukan stack di sekitar kita!

LAPIS 3 📖 Penamaan Konsep — Istilah Resmi

🏷️ Sekarang, Kita Beri Nama!

Semua yang kamu jelajahi tadi — text editor, browser history, tumpukan piring — semuanya memakai struktur data yang sama: stack (tumpukan). Inilah saatnya menghubungkan pengalamanmu dengan istilah formal.

📚 Penerapan Stack di Sekitar Kita

Tabel Penerapan Stack:

Penerapan Cara Kerja Stack
Undo/Redo Stack pertama menyimpan aksi yang dilakukan. Undo = Pop. Redo = Push ke stack kedua (redo). Untuk Redo, dibutuhkan dua stack: stack undo dan stack redo.
Browser Back/Forward Stack riwayat halaman. Back = Pop dari stack back. Forward = Push kembali ke stack riwayat. Sama seperti Undo/Redo, browser butuh dua stack.
Tumpukan Fisik Piring, nampan, buku — yang terakhir diletakkan, pertama diambil (LIFO).
Contoh Lain Chat WhatsApp (edit pesan), aplikasi edit foto (Undo), permainan kartu (tumpukan kartu di meja), call stack pada program.
💡 Koneksi Dunia Nyata:
Saat kamu mengedit pesan WhatsApp dan menekan tombol hapus, itu mirip Pop di stack. Saat kamu membatalkan edit dan mengembalikan pesan semula, itu mirip Redo. Bahkan saat kamu menumpuk buku pelajaran di meja, kamu sedang melakukan Push di stack fisik!
