📚 Materi Singkat — Bagian 3

Stack banyak dipakai di teknologi sehari-hari. Salah satu contoh paling nyata adalah tombol Back di browser. Browser menyimpan riwayat halaman yang kamu kunjungi dalam sebuah stack.

  • Setiap kali kamu membuka halaman baru → Push URL ke stack riwayat.
  • Setiap kali kamu klik Back → Pop dari stack riwayat.
  • Halaman yang muncul adalah halaman yang terakhir dikunjungi sebelum halaman saat ini.

Contoh lain: tombol Undo (Ctrl+Z), riwayat chat WhatsApp, call stack di program komputer, dan tumpukan buku di meja belajar.

Aktivitas Interaktif — Simulasi Riwayat Browser

Buka beberapa website Indonesia dengan mengklik tombol di panel kanan. Amati bagaimana stack riwayat bertambah setiap kali kamu membuka situs baru. Lalu gunakan tombol ← Back dan → Forward di browser mini untuk menjelajah riwayat.
