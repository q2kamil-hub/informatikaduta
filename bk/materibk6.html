Bagian 1: Apa Itu Tumpukan (Stack)?

1.1 Pengertian Tumpukan

Tumpukan (Stack) adalah cara komputer mengorganisasi data dengan aturan khusus: data yang terakhir masuk adalah data yang pertama keluar. Aturan ini disebut LIFO (Last In First Out).

Bayangkan tumpukan piring di rak dapur:

  • Piring yang terakhir ditaruh (paling atas) akan pertama diambil.
  • Piring yang pertama ditaruh (paling bawah) akan terakhir diambil.
  • Kamu tidak bisa mengambil piring dari tengah atau bawah tanpa mengambil piring di atasnya terlebih dahulu.
Analogi: Tumpukan piring di rak dapur adalah contoh paling mudah dari stack. Ibu selalu mengambil piring paling atas, bukan piring paling bawah.

1.2 Elemen Penting dalam Stack

Istilah Penjelasan Analogi Piring
TOP Elemen paling atas, satu-satunya yang bisa diakses Piring paling atas
Push Operasi menambah data ke atas tumpukan Menaruh piring baru di atas
Pop Operasi mengambil data dari atas tumpukan Mengambil piring paling atas
IsEmpty Pemeriksaan apakah tumpukan kosong Cek apakah rak piring kosong

1.3 Mengapa Belajar Stack?

Stack adalah salah satu struktur data fundamental dalam ilmu komputer. Banyak teknologi yang kamu gunakan sehari-hari bekerja dengan prinsip stack:

  • Tombol Back di browser (Chrome, Firefox): Halaman yang terakhir kamu kunjungi adalah yang pertama muncul saat kamu klik Back.
  • Tombol Undo (Ctrl+Z) di aplikasi edit teks: Perubahan terakhir yang dibatalkan terlebih dahulu.
  • Riwayat perintah di aplikasi Gojek atau Tokopedia.

Bagian 2: Operasi pada Tumpukan (Push, Pop, Top)

2.1 Tiga Operasi Utama Stack

Stack memiliki operasi-operasi dasar yang terbatas. Keterbatasan ini justru yang membuat stack sangat efisien untuk kasus tertentu.

Operasi Fungsi Analogi
Push Menambahkan elemen ke posisi TOP Menaruh piring di atas tumpukan
Pop Mengambil dan menghapus elemen dari TOP Mengambil piring paling atas
Top Melihat elemen TOP tanpa menghapusnya Melihat piring paling atas tanpa mengambilnya
IsEmpty Memeriksa apakah stack kosong Mengecek rak piring

2.2 Ilustrasi Operasi Stack

Skenario: Dewi menumpuk 3 buku di perpustakaan.

Langkah 1: Push("Matematika") ┌─────────────┐ │ Matematika │ ← TOP └─────────────┘ Langkah 2: Push("IPA") ┌─────────────┐ │ IPA │ ← TOP ├─────────────┤ │ Matematika │ └─────────────┘ Langkah 3: Push("Bahasa") ┌─────────────┐ │ Bahasa │ ← TOP ├─────────────┤ │ IPA │ ├─────────────┤ │ Matematika │ └─────────────┘ Langkah 4: Pop() ┌─────────────┐ │ IPA │ ← TOP ├─────────────┤ │ Matematika │ └─────────────┘ (Hasil Pop: "Bahasa")

2.3 Aturan Penting

  • Push hanya bisa dilakukan jika stack belum penuh.
  • Pop hanya bisa dilakukan jika stack tidak kosong.
  • Operasi stack bersifat O(1) atau waktu konstan — seberapa pun banyaknya data, kecepatan operasi tetap sama.

Bagian 3: Penerapan Stack dalam Kehidupan Sehari-hari

3.1 Stack di Dunia Nyata

Konsep stack bukan hanya teori di buku. Banyak teknologi dan aktivitas sehari-hari menggunakan prinsip LIFO.

Penerapan Penjelasan Contoh Konteks Indonesia
Tombol Undo Perubahan terakhir dibatalkan pertama Ctrl+Z di Microsoft Word saat menulis tugas
Browser Back Halaman terakhir dikunjungi pertama kembali Klik Back setelah browsing di Tokopedia
Riwayat Chat Pesan terakhir muncul paling atas Chat WhatsApp dengan teman
Call Stack Fungsi yang terakhir dipanggil selesai pertama Program komputer saat menjalankan aplikasi
Tumpukan Buku Buku terakhir ditaruh diambil pertama Tumpukan buku pelajaran di meja belajar

3.2 Studi Kasus: Tombol Back di Browser

Ketika kamu membuka website:

  1. Buka Google → Stack: [Google]
  2. Buka Ruangguru → Stack: [Google, Ruangguru]
  3. Buka Tokopedia → Stack: [Google, Ruangguru, Tokopedia]
  4. Klik Back → Kembali ke Ruangguru. Stack: [Google, Ruangguru]
  5. Klik Back lagi → Kembali ke Google. Stack: [Google]

Inilah mengapa tombol Back selalu mengembalikan ke halaman sebelumnya, bukan ke halaman pertama.

3.3 Studi Kasus: Gotong Royong di Sekolah

Bayangkan kegiatan gotong royong membersihkan kelas:

  • Setiap siswa yang selesai membersihkan area, namanya dicatat di papan tulis (Push).
  • Ketika guru ingin memanggil siswa untuk membantu memindahkan meja, ia memanggil siswa yang terakhir selesai (Pop) — karena siswa tersebut masih berada di area dan siap membantu.

Ini adalah prinsip LIFO dalam konteks budaya Indonesia.
