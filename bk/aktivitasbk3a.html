📖 Materi Singkat Bagian 1

1. Apa Itu Mesin Komputasi?

Mesin komputasi adalah gambaran sederhana dari fungsi di dalam komputer. Seperti mesin pada umumnya, fungsi menerima masukan (input), memprosesnya sesuai aturan, dan menghasilkan keluaran (output). Konsep ini disebut juga Input → Proses → Output (I-P-O).

2. Tiga Komponen Utama

  • Input (Masukan): data yang diberikan, misalnya angka, teks, atau perintah.
  • Proses (Pengolahan): langkah atau aturan yang mengubah input menjadi output.
  • Output (Keluaran): hasil akhir dari proses, bisa berupa angka, pesan, atau tampilan.

3. Contoh dalam Kehidupan Sehari-hari

🥤 Mesin penjual otomatis:
  • Input: uang + pilihan minuman
  • Proses: membaca pilihan, mengambil minuman, menghitung kembalian
  • Output: minuman keluar + kembalian
🧮 Kalkulator:
  • Input: angka 5, 3, dan tombol "+"
  • Proses: menjumlahkan 5 + 3
  • Output: angka 8 di layar

4. Mengapa Penting?

Dengan mengenali Input → Proses → Output, kita bisa memahami cara kerja komputer dan menyusun solusi yang terstruktur. Ini juga dasar dari semua bahasa pemrograman!
