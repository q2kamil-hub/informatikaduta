📖 Penerapan dalam Kehidupan Sehari-hari

Setelah menguasai konversi bilangan, sekarang saatnya melihat bagaimana konsep ini diterapkan dalam kehidupan nyata.

1. Kode Warna dalam Desain Web

Warna di halaman web direpresentasikan dengan kode heksadesimal (basis 16) yang merupakan "kerabat dekat" biner. Contoh: warna putih = #FFFFFF, yang dalam biner adalah 11111111 11111111 11111111.

2. Kapasitas Penyimpanan

Memahami bit dan byte membantu kita mengelola penyimpanan. 1 byte = 8 bit. File video 500 MB = sekitar 4.000.000.000 bit.

3. Kode ASCII untuk Teks

Setiap huruf dan simbol di keyboard memiliki kode biner. Contoh: huruf "A" = 01000001 (65 desimal), huruf "a" = 01100001 (97 desimal).

4. Parity Bit untuk Deteksi Kesalahan

Saat data dikirim melalui jaringan, bit tambahan (parity bit) ditambahkan untuk mendeteksi kesalahan. Jika jumlah bit 1 ganjil/genap tidak sesuai, data dianggap rusak.

5. Sandi dan Keamanan Digital

Konsep biner digunakan dalam enkripsi dan sandi digital, termasuk pengaturan jaringan Wi-Fi.
