1. Apa Itu Antarmuka Pengguna (User Interface)?

Antarmuka pengguna adalah jembatan yang menghubungkan pengguna dengan perangkat digital. Ada beberapa jenis antarmuka:

  • GUI (Graphical User Interface) — menggunakan ikon, tombol, dan elemen visual. Contoh: desktop Windows, layar ponsel.
  • CLI (Command Line Interface) — menggunakan perintah teks. Contoh: Terminal Linux, Command Prompt.
  • VUI (Voice User Interface) — menggunakan suara. Contoh: Siri, Google Assistant.
💡 Mengapa GUI lebih populer? Karena GUI lebih intuitif — pengguna cukup memilih perintah dalam bentuk ikon atau tombol, tanpa menghafal perintah teks yang rumit.

2. Memahami GUI (Graphical User Interface)

GUI adalah antarmuka yang menggunakan ikon dan elemen grafis sebagai pengganti perintah berbasis teks. Konsep ini pertama kali dikembangkan secara komersial pada tahun 1984 oleh Apple Computer, dan kini menjadi standar di hampir semua sistem operasi.

🚦 Analogi: GUI seperti papan tanda di jalan raya. Tanpa tanda, kita bingung arah; dengan tanda, kita tahu harus belok kiri, kanan, atau terus.

3. WIMP System

Sebagian besar GUI menggunakan sistem WIMP:

WIMP = Windows, Icons, Menus, Pointing
  • Windows — jendela area kerja program
  • Icons — simbol visual program/file/folder
  • Menus — daftar pilihan perintah
  • Pointing — pointer (mouse/sentuhan) untuk memilih
