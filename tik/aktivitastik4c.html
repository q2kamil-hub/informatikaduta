LAPIS 3 📖 Penamaan Konsep — Istilah Resmi

🏷️ Sekarang, Kita Beri Nama!

Semua yang kamu lakukan tadi punya nama resmi dalam literasi digital. Inilah saatnya menghubungkan pengalamanmu dengan istilah formal.

🔍 Mengakses file adalah "menemukan pintu" — ada beberapa cara, dan setiap cara punya kelebihan.

Tiga cara mengakses file:
  • Jalur folder (Path) — presisi, tahu lokasi pasti, tetapi harus mengingat jalur. Cocok untuk file yang sering dibuka.
  • Search — cepat, tidak perlu ingat jalur, tetapi hasil bisa banyak. Cocok untuk file yang jarang dibuka.
  • Shortcut — sangat cepat, tetapi harus dibuat dulu. Cocok untuk file yang sangat sering dibuka.

Apa itu "path"?
Path adalah "alamat" file di komputer. Contoh:
C:\Users\Dewi\Documents\Tugas\Informatika\Tugas Informatika.docx

Struktur path:
  • C: — drive
  • Users\Dewi\Documents — folder
  • Tugas\Informatika — subfolder
  • Tugas Informatika.docx — nama file
💡 Koneksi Dunia Nyata:
Saat kamu mengirim tugas lewat Google Classroom, kamu perlu tahu di mana file-mu tersimpan. Saat kamu menggunakan Google Drive, search dan shortcut adalah fitur yang sangat membantu. Bahkan di HP Android, kamu bisa membuat shortcut aplikasi di layar utama — itu adalah prinsip yang sama.
