LAPIS 3 📖 Penamaan Konsep — Istilah Resmi

🏷️ Sekarang, Kita Beri Nama!

Semua yang kamu lakukan tadi punya nama resmi dalam literasi digital. Inilah saatnya menghubungkan pengalamanmu dengan istilah formal.

✏️ Mengelola file adalah "merawat rumah" — tidak cukup hanya membangun, tetapi juga menjaga kerapian.

Prinsip penamaan file yang baik:
  • Jelas — menggambarkan isi file.
  • Konsisten — mengikuti pola yang sama.
  • Ringkas — tidak terlalu panjang.
  • Mengandung versi — jika ada revisi, gunakan v1, v2, atau tanggal.

Contoh pola penamaan:
  • [Mapel]_[Jenis]_[Versi] → Informatika_Tugas_v2.docx
  • [Tanggal]_[Kegiatan] → 2024-03-15_Pramuka.jpg
  • [Kategori]_[Deskripsi] → Dokumen_LaporanBanjir.pdf

Operasi dasar pengelolaan file:
  • Rename — mengubah nama file
  • Move — memindahkan file ke folder lain
  • Copy — menduplikasi file
  • Delete — menghapus file
  • Search — mencari file berdasarkan nama
💡 Koneksi Dunia Nyata:
Saat kamu mengumpulkan tugas lewat Google Classroom atau Google Drive, guru akan lebih mudah memeriksa jika nama file-mu jelas. Di dunia kerja nanti, kemampuan mengelola file dengan rapi adalah keterampilan yang sangat dihargai.
