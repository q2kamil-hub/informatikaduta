Membuat & Mengelola Folder dan File dengan Terstruktur
Struktur yang Rapi · Penamaan yang Jelas · Akses yang Cepat
📚 Selamat datang! Modul ini akan membimbingmu memahami bagaimana membuat folder, mengelola file, dan mengaksesnya dengan efisien — sehingga kamu tidak lagi membuang waktu mencari file yang tertumpuk tanpa struktur.

Kamu akan mempelajari:
  • Membuat folder — "membangun rumah untuk file-file"
  • Mengelola file — rename, pindah, copy, hapus dengan bijak
  • Mengakses file — jalur folder, search, dan shortcut
  • Konteks lokal — Google Drive, flashdisk, laptop lab komputer

Di setiap bagian, kamu bisa memilih tingkat tantangan: 🟢 Dasar · 🟡 Reguler · 🔴 Tantangan. Sesuaikan dengan kesiapanmu!
